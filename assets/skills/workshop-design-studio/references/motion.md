# Motion

Motion should explain change, preserve spatial continuity, or create a deliberate emotional moment.

- Feedback: 80–180ms.
- Common transitions: 150–300ms.
- Larger choreographed transitions: 300–700ms when justified.
- Exit usually completes faster than entry.
- Prefer transform and opacity for performance.
- Avoid animating layout properties repeatedly.
- Allow interruption and avoid trapping the user in animation.
- Respect `prefers-reduced-motion`.
- Use one signature sequence rather than animating every component.
