# Data visualisation

Choose a chart from the question:

- trend over time → line or area;
- category comparison → bar;
- part-to-whole → stacked bar, or pie only for a few simple parts;
- relationship → scatter;
- distribution → histogram/box plot;
- flow → Sankey when paths are the question;
- geography → map only when location matters;
- detailed comparison → table or heatmap.

Use honest scales, clear units, direct labels where possible, and textual summaries.
Do not add charts as decoration. Data-heavy applications still need a strong visual concept.
