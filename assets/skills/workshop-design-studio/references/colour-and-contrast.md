# Colour and contrast

Use colour as a system of roles:

- canvas and surfaces;
- primary text and muted text;
- brand/action;
- border/divider;
- information, success, warning, danger;
- charts or categorical data.

## Rules

- Check foreground/background contrast rather than trusting palette labels.
- Never encode status by colour alone.
- Use saturation strategically; large saturated areas need strong justification.
- Dark mode is a separate composition and contrast problem, not a simple inversion.
- Repeated raw hex values belong in tokens, not feature components.
- A bold branded website may use vivid colour; a regulated workflow may require restraint.
