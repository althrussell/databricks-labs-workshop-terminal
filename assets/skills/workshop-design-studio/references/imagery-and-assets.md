# Imagery and assets

## Strategy

Pick one dominant asset language:

- documentary photography;
- premium product macro;
- architectural/technical diagrams;
- painterly or vector illustration;
- abstract geometry;
- generative texture;
- icon-led minimalism.

## Production rules

- Use official or user-provided assets first.
- Store production assets locally.
- Optimise raster formats and reserve layout space.
- Provide meaningful alt text; decorative images use empty alt.
- Keep illustration perspective, line weight, lighting, and palette consistent.
- Avoid mismatched stock imagery and random icon packs.
