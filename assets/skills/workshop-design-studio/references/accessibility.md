# Accessibility

Minimum quality gates:

- keyboard-operable interactions;
- visible focus;
- logical focus order;
- labels for fields and icon-only controls;
- semantic headings and landmarks;
- meaningful alt text;
- contrast suitable for text and controls;
- status not conveyed by colour alone;
- reduced-motion support;
- responsive zoom and no disabled viewport scaling;
- error messages connected to fields;
- chart alternatives or data tables.

Accessibility is part of visual quality, not a later compliance pass.
