# Signature moments

A signature moment creates memorability without overwhelming the experience.

Examples:

- product reveal that responds to scroll;
- interactive data transformation;
- refined command palette;
- animated process diagram;
- comparison slider;
- conversational AI trace with meaningful tool states;
- branded empty state;
- spatial canvas;
- tactile drag/configuration interaction;
- elegant transition between overview and detail.

One strong moment is usually enough. It must remain usable with reduced motion.
