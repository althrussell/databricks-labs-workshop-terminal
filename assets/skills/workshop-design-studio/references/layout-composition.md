# Layout and composition

## Establish hierarchy

- One dominant message or work surface per viewport.
- Use scale, contrast, position, whitespace, and rhythm intentionally.
- Keep reading measure appropriate to content.
- Align elements to a visible grid.
- Let major sections differ in rhythm while preserving system consistency.

## Avoid template sameness

Replace default card grids with the grammar that fits the content:

- continuous panes for workbenches;
- editorial sections for storytelling;
- comparative tables for decision-making;
- full-bleed product moments for premium experiences;
- asymmetric modular systems for creative products;
- compact rows for operational density.

## Responsive composition

Responsive design may reorder, collapse, crop, simplify, or change interaction.
It is not desktop scaled down.
