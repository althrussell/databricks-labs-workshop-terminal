# Workshop fast path

The default mode for a workshop session. Every step is yours to execute — none
of them involve the attendee.

## 60-minute target

- 0–5: discover product, audience, brand evidence, stack, and primary action.
- 5–10: generate three directions internally, select one, record the reason.
- 10–15: persist the compact design system.
- 15–40: implement one complete primary route.
- 40–50: critique pass A and revise.
- 50–57: critique pass B, responsive and accessibility fixes.
- 57–60: audit, quality gate, build, screenshot, record verification.

The selection at 5–10 is a decision you make and write down, not a menu you
present. An attendee who is asked to choose a creative direction has been given
homework they came here to avoid.

## Scope control

Prefer one extraordinary route and one supporting state over several generic
pages. Use existing assets and libraries. Do not spend the workshop rebuilding
infrastructure.

## When time runs short

Cut scope, never craft. Drop the second route, the extra states, the optional
signature moment. Do not drop the critique passes, the accessibility checks, or
the quality gate — those are the difference between a designed product and a
framework starter with new colours.
