# Typography

Typography creates most of the perceived quality in text-heavy interfaces.

- Use a display face only when it strengthens the concept.
- Use a highly readable body face with broad character coverage.
- Define optical hierarchy: display, title, heading, body, label, metadata, code.
- Control line length, leading, letter spacing, and paragraph rhythm.
- Use tabular figures for changing metrics and aligned financial/data values.
- Use mono type selectively for code, identifiers, and technical metadata.
- Prefer variable fonts only when the loading strategy is safe.
- Always provide robust system fallbacks.
- Avoid more than two type families unless the concept justifies it.
